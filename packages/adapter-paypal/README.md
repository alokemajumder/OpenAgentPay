# @openagentpay/adapter-paypal

PayPal Orders API adapter with OAuth2 authentication and credit bridge.

## Install

```bash
npm install @openagentpay/adapter-paypal
```

## Usage

```typescript
import { paypal } from '@openagentpay/adapter-paypal';

const adapter = paypal({ clientId: '...', clientSecret: '...' });
```

See the [main documentation](../../README.md) for full details.
