# @openagentpay/adapter-visa

Visa Intelligent Commerce adapter supporting Visa MCP and AgentCard virtual debit cards.

## Install

```bash
npm install @openagentpay/adapter-visa
```

## Usage

```typescript
import { visa } from '@openagentpay/adapter-visa';

const adapter = visa({ merchantId: '...', apiKey: '...' });
```

See the [main documentation](../../README.md) for full details.
